# Pamuditha Silva Portfolio

A responsive personal portfolio built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Vite will print the local address, usually `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

The build output is written to `dist/` and can be deployed to any static hosting provider.

## Updating content

Portfolio details, skills, projects, education, and achievements are maintained in [src/data.ts](src/data.ts). The profile image is at `src/assets/profile.jpg`.

## Project structure

```text
src/
  assets/       Profile image
  components/   Page sections and navigation
  data.ts       Portfolio content
  index.css     Global theme and reusable utilities
  App.tsx       Page composition
```
